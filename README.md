GYMFIT 🏋️‍♂️

GYMFIT is a feature-rich fitness and gym management web application designed to help users track workouts, manage nutrition plans, connect with trainers, and upgrade to premium membership tiers through an interactive web interface.

🚀 Features

📊 Interactive Dashboard displaying daily workout status and metrics

💪 Comprehensive Workout Plans & Custom Routines

🥗 Nutrition and Diet Plan tracking

👑 Premium Membership Upgrades with flexible subscription durations (e.g., 6 Months)

👨‍🏫 Trainer Directory and Support

👤 User Profile and Account Management with secure password changes

📈 Progress and BMI Tracking

🌐 Modern, responsive dark-themed UI/UX design

🎯 Project Purpose

The purpose of GYMFIT is to build a comprehensive fitness tracking and gym membership web application that combines user profile management, structured workout/diet scheduling, trainer interaction, and subscription-based tier management.

The project demonstrates experience with:

Interactive dashboard and UI design

Membership and subscription tier handling

Profile and account settings management

Fitness data tracking (workouts, nutrition, and progress)

Responsive layout development
